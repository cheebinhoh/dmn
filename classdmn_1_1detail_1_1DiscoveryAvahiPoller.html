Detailed Description

Avahi poll/client lifetime owned by DiscoveryCommandWorker.

The handler is an internal state-worker callback, never application code. On failure it must invalidate objects belonging to that client before returning. Cleanup must release all remaining client-owned objects before returning, including when it reports an error. The optional drive callback runs on the worker before each poll; it must process due work and return the earliest remaining monotonic deadline. The command worker serializes start, wait and stop; only wake is concurrent.
