Detailed Description

Platform-neutral DNS-SD discovery API declarations and owned values.

Copyright © 2026 Chee Bin HOH. All rights reserved.

API Boundary

This header defines the portable application-facing contract for explicit service browsing and registration. It exposes no Avahi, Bonjour, D-Bus or other native types. The optional Linux implementation uses Avahi; the macOS implementation uses Bonjour.

Ownership and Threading

Values crossing the API boundary own their strings and byte sequences. Client, browser and registration operations are intended to be thread-safe. A client owns its state worker and serialized callback worker; native callbacks do not run application handlers. Handlers must not throw, block indefinitely, destroy a handle/client, or call barrier operations such as clearCache(), stop() or shutdown(). A callback may run before the call that accepted it returns. See the discovery specification for complete lifecycle and drain-barrier semantics.

Discovery is a local observation, not an inventory, reachability check or trusted identity. TXT data is opaque untrusted data.
