Detailed Description

One owned IP address and its optional IPv6 scope interface.

bytes contains exactly four bytes for IPv4 or sixteen for IPv6. interface_index is the scope for a scoped address when known; an IPv6 link-local address without a known scope is not a usable endpoint.
