Detailed Description

template<typename Derived, typename T>
class dmn::Dmn_BlockingQueue< Derived, T >

Dmn_BlockingQueue is the top-level class for the abstraction and implementation classes in the Bridge pattern, using CRTP to achieve static polymorphism.

  • There are a set of primitive methods to be overridden by concrete implementation subclasses. Those methods are protected virtual implementation hooks and are defined in this class with CRTP to achieve static polymorphism when calling subclass implementations. They correspond to methods in the implementation tree in the Bridge design pattern.
  • There are a set of composite methods that are marked as final and implemented in terms of primitive methods. These correspond to methods in the abstraction tree in the Bridge design pattern.

Remove and return the front item, waiting until an item is available.

If the queue is empty, this call blocks or waits until either:

  • an item is pushed, in which case that item is removed and returned, or
  • shutdown begins, then the method throws an exception.
