Detailed Description

Private, caller-serialized browser state used by deterministic tests.

Contributions merge by DNS-aware key and are independently removed. Each contribution receives an opaque generation, allowing a caller to reject callbacks that arrive after removal and re-addition. This initial model delivers callbacks synchronously; it is not the final threaded public API.

Apply one record-model update from a current browse source.

The update runs synchronously on the caller-serialized browser. The callback receives the live source token and must not retain the model reference, alter browse-source membership, or re-enter browser mutation methods. An exception from the update leaves the prior state unchanged. Observable changes are published after the update, including changes caused by an unsuccessful update; the session handles publication failures.
