Detailed Description

Environment-trusted TCP adapter for isolated deployments.

This adapter provides framing and DMesgNet wiring only. It deliberately performs no cryptographic authentication; callers must use it only when the network boundary is trusted. The future authenticated adapter can reuse the same session and factory boundary.
