auto dmn::detail::parseAncsNotificationSource ( std::span< const std::uint8_t > value) ->Dmn_AncsValueResult< Dmn_AncsNotification >
nodiscard

Parse one ANCS Notification Source notification value.

A valid value is exactly eight bytes. Unknown category and flag bits are retained verbatim; an unknown event ID is returned as a nonfatal Unsupported error so a session can report and ignore it.
