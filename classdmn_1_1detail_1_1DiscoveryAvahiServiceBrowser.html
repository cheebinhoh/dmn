Detailed Description

Own a single native browser on the Avahi state worker.

Handlers are internal state-worker functions, never application callbacks. A handler may run synchronously inside start(). It must not destroy or stop this browser; the owner handles a reported failure after the callback. The owner must destroy the browser before its AvahiClient.
