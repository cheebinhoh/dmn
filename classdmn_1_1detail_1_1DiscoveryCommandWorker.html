Detailed Description

One serialized worker with finite ordinary and control admission.

Work runs outside the queue lock. A barrier command must not wait for user callback completion on this worker; its caller coordinates that drain. The owner externally coordinates destruction with method calls.

Execute an operation on the state worker and wait for its result.

A native callback already on this worker executes directly without queueing or waiting for itself. Such callbacks must not hold locks that the command acquires. Other threads use bounded ordinary admission.
