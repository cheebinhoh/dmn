Detailed Description

Explicit browse session with an owned snapshot and event stream.

The browser owns its local view only. clearCache() resets this browser's view and work; it does not flush a system daemon cache or affect another browser. stop() is an idempotent callback-drain barrier. Snapshot state remains inspectable after stop or client shutdown.
